# 侧边栏面板图标

默认：开

左侧栏顶部只保留一排图标：大号「新会话」按钮收成图标，排在面板图标（插件、自动化任务、上下文洞察、过程叙述等）前面，「更多」入口同样是一个图标，鼠标悬停时显示对应名称。点「新会话」图标的行为与大按钮一致。

列表末尾还有一个形态切换按钮：点一下切回官方布局（大号「新会话」按钮 + 「图标 + 文字」的竖排面板列表），再点一下恢复图标排。选择写入 `features.sidebarPanels`，与设置页开关是同一个值。

宿主侧边栏结构有两种：0.2.2-rc.1 及更早，面板列表的直接子元素就是按钮；0.2.2-rc.3 起改为 `panelEntry` 包装层，里面才是带标题与「取消固定」按钮的行。插件按实际结构套用对应样式，识别不到时不做装饰；侧边栏折叠时交给宿主原生的图标态，形态切换按钮与「新会话」图标一起收起。
