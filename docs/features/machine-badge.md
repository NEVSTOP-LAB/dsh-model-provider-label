# 本机标识

默认：开

两处显示同一台机器的名字，作用是远程连接多台机器时一眼分辨当前看的是哪一台：

- 左侧栏底部独占一行：图标 + 本机名称，排在「工具箱」条目下面、头像上面；侧栏收起成轨道时只留图标；
- 浏览器标签页标题带同一前缀，例如 `[办公室主机] 会话标题 — DeepSeek Harness`。

名称为空时使用主机名。远程机器的主机名常常是 `DESKTOP-8F3K2` 这类认不出的字符串，在设置页填一个「本机显示名」更实用；名称改动后两处立即跟着变。

主机名、登录用户、平台与 DSH 版本在设置页「本机标识」卡片里查看。这些信息由 Host 提供——浏览器里 `location.host` 是隧道地址或 `127.0.0.1`，判断不了机器。取得不到信息时只显示名称，不影响开关。

关闭后侧栏那行与标题前缀一起消失。

> [!NOTE]
> 走公网隧道访问时，主机名与登录用户名会显示给能打开这个页面的人。主标识建议只填别名，详情里的信息按需查看。
